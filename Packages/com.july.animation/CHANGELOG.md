# Changelog

## 0.2.2 - 2026-08-12

- Allow callers to select the one-shot Animator state at runtime while preserving the configured loop state.

## 0.2.1 - 2026-08-11

- Added `AnimatorOneShotLoopPlayer` for playing one Animator state once before continuously looping another state.

## 0.2.0 - 2026-07-22

- Catch up multiple sprite frames after a long or low-frame-rate update.
- Resolve SpriteRenderer and Image targets from child objects when absent on the host.

## 0.1.1

- Added reusable simple animation components and sprite frame animation.
