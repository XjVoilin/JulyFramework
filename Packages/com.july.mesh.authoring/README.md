# July Mesh Authoring

Unity 2022.3 编辑器专用静态 Mesh 简化工具。入口：**JulyGF → 资源管理 → Mesh 简化**。

当前版本 0.1.4，内置 **meshoptimizer 1.0，Windows x86_64 Editor** 原生库。无 Runtime 程序集，依赖 July Logging 输出操作失败，不依赖 URP、JulyArch、YooAsset 或具体游戏。

## 使用

1. 选择独立 `.asset` Mesh、Prefab、文件夹或场景对象，点击“读取所选”。工具收集实际引用的独立 Mesh，同一资源只列一次。
2. 模型内嵌 Mesh、临时 Mesh 和其他子资源会跳过并提示。FBX 不参与减面；应先由项目自己的 Prefab 制作流程提取为独立 Mesh，再处理正式使用的资源。
3. 首次读取自动推荐。每行显示“当前 / 调整后”Mesh 缩略图和面数，右侧直接输入或拖动保留比例，候选随计算完成刷新。手动调整不受自动推荐的误差上限限制，仍保留必要的边界与接缝保护。
4. 行内“恢复推荐”回到该项推荐；“全部恢复推荐比例”作用于全部条目，包括未勾选项。这两项操作仅修改候选。
5. “应用勾选”原位保存独立 Mesh，保留 GUID 和 Local ID，影响该资源全部引用者。应用后当前面数、预览和待应用统计立即更新；重新读取或重开窗口显示已应用状态，不覆盖为推荐结果。
6. “还原勾选资源”写回本机缓存的基准；也可手动调回 100% 后应用。缓存有效时，每次调整都从同一基准生成，不累计减面损失。

缩略图只使用中性材质显示 Mesh；单击资源名或缩略图定位资源，不提供双击大图。纹理、材质和正式光照下的表现仍需结合场景复核。

默认窗口 1100×800，已打开窗口保留大小。默认名称自然升序；保留比例首次升序、减少面数首次降序，再次点击反转。数值排序按实际候选计算；读取新列表时排序一次，此后仅点击排序按钮才重排，修改比例、完成计算或恢复推荐均保持当前行位置。

工具栏提供“全选”和“取消全选”，作用于列表全部 Mesh，包括滚动区域外的项目；仅更新勾选及统计，不改变比例、候选或当前顺序。

底部显示勾选候选预计减少的总面数：**当前面数 − 候选面数**，每个 Mesh 计一次，不乘实例数。计算中、无候选或存在错误的项目暂不计入，并显示未计入项数。提高比例时可以显示预计增加的面数。

## 资源与本机基准

- 正式 Mesh 由项目管理，工具不在 Assets 下创建备份、记录或替代 Mesh，也不修改 Prefab / 场景引用。
- 应用简化、还原基准及写入失败回退均保留目标资源操作前的 Read/Write 设置；编辑器读取网格不要求开启该设置。
- 基准及已应用比例保存在 `Library/July/MeshAuthoring/`，只属于当前电脑，不纳入版本管理。
- 缓存缺失或资源内容与缓存不符时，以当前 Mesh 建立新基准；当前资源就是新的 100%。因此删除 Library、换电脑或更新源 Mesh 后，不承诺恢复历史原版。
- 外部编辑发生在预览之后时，本次应用 / 还原会拒绝覆盖，要求重新读取。读取后基于最新内容重新建立有效基准。
- 旧版 `Assets/JulyMeshSimplification/Generated/` 中的独立 Mesh 可作为普通 Mesh 使用。新流程不解析旧记录、不映射回 FBX、不迁移引用、不自动删除旧文件。仅保留 `MeshEditRecord` 的被动序列化结构，避免现有记录变成 Missing Script；没有旧流程的执行代码。
- 模型提取与模型更新不属于本库。项目的生成工具负责资源命名、输出目录、共享和重复生成策略。

批量应用可取消，已完成项保留，显示未处理数量；不承诺整批事务。后台计算串行合并请求，过期结果不会覆盖新输入；同步原生调用不能中途打断，窗口关闭后结果丢弃。

## 支持范围

处理 Assets 内可写的独立静态三角 Mesh，保留完整顶点缓冲、UV 通道维度、法线、切线、顶点色、子网格与材质槽。法线 / UV / 颜色的算法属性分量合计超过 32 时拒绝处理。

不处理骨骼、BlendShape、非三角拓扑、临时来源、模型子资源及只读来源。不重烘焙法线贴图 / 光照，不重建碰撞体。Mesh 与 MeshCollider 共用时拒绝原位修改；检查已加载对象和持久化 Prefab / Scene，必要时临时加载相关场景并关闭，不保存场景。运行时代码动态赋值的用途无法静态证明。

保真档近似误差阈值为 0.001 / 0.003 / 0.01；法线权重 0.5、UV 分量 10、顶点色分量 1。这些是工程参数，不是人眼变化百分比。手动目标不保证精确达到，界面显示实际比例。

## 验证与重建

在 manifest 的 `testables` 加入 `com.july.mesh.authoring`，通过 EditMode Test Runner 运行 `July.Mesh.Authoring.Tests`。测试创建并清理独立临时资源，不应与生产资源编辑同时执行。

`Native~/` 包含 meshoptimizer 官方源码快照、桥接源与 CMake 配置；版本 `v1.0`，提交 `73583c335e541c139821d0de2bf5f12960a04941`，MIT 许可见 `Third Party Notices/meshoptimizer-LICENSE.txt`。DLL 仅启用 Windows x86_64 Editor。
