# July Analytics ThinkingData

Strongly typed default `IAnalyticsChannel` implementation for ThinkingData Unity SDK 3.4.2.
The vendor-neutral analytics contracts remain in `com.july.analytics`.

This package owns the SDK source used by the adapter. The bundled variant preserves the
WeChat mini-game define compatibility and PC time-zone fallback verified by GooseMarket.
The upstream SDK is licensed under Apache-2.0.
