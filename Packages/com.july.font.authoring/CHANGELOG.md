# Changelog

## 0.1.1 - 2026-11-11

- Automatically discover and probe Python 3.10+ with pip from PATH, Windows Python registrations and launchers; show the actual executable and version with no manual path setting.
- Open the output directory after successful generation and remove the locate-output button.

## 0.1.0 - 2026-11-11

- Add a standalone Editor-only source font subsetting package and Unity window.
- Merge default GB2312/ASCII/symbols with extra text and UTF-8 character files by Unicode codepoint.
- Install pinned fontTools into project-local Library, with asynchronous execution, cancellation and process cleanup.
- Precheck source coverage, require explicit missing-glyph/overwrite acknowledgment, and verify preserved source characters before publishing sibling output.
